# Video — Remotion

Videos programáticos de Mirada Digital hechos con [Remotion](https://github.com/remotion-dev/remotion) (React → MP4).

```bash
cd video
npm install
npm run dev      # abre Remotion Studio para previsualizar y editar
npm run render   # exporta out/intro.mp4
```

- `src/Root.tsx` — registra las composiciones (tamaño, fps, duración).
- `src/Intro.tsx` — composición de ejemplo 1080x1920 (reel) con los colores de marca.
